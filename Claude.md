# Project Context

This project is a landing page built with React and TypeScript.

## Goal

Create a clean, modern, responsive landing page for a client. The site should be easy to maintain, visually professional, and optimized for conversion.

## Tech Stack

- React

- TypeScript

- Vite or Next.js, depending on the project setup

- CSS / Tailwind / custom styles depending on existing files

- Calendly integration may be added later

## Project Rules

- Keep the code simple and maintainable.

- Do not overcomplicate the structure.

- Prefer reusable components only when they make sense.

- Preserve the existing visual style unless asked otherwise.

- Make the site fully responsive for mobile, tablet, and desktop.

- Avoid unnecessary dependencies.

- Use TypeScript properly.

- Keep components readable and well organized.
